# CRPS Monitor (CRPSR0)

Android 应用，通过蓝牙连接 ESP32-C3 采集模块，实时监测 CRPS 服务器电源参数。

## 功能特性

### 📊 实时数据监测
- **电源控制页**：显示输入电压/电流、输出电压/电流、输出功率、转换效率、温度等实时数值
- **数据曲线页**：三组实时滚动图表
  - 电压电流曲线（双 Y 轴）
  - 功率效率曲线（左轴功率 + 右轴效率固定 0-100%）
  - 温度曲线（环境温度 + 热点温度）
- 60fps 匀速滚动，支持暂停/恢复
- 支持拖动查看历史数据
- 断联自动暂停，恢复后继续
- 效率数据经 EMA 滤波平滑显示

### 🔌 远程控制
- 电源开机/关机远程控制
- 电源状态实时同步（开机/关机/启动中/停止中/错误）
- 防误操作确认弹窗

### 🎨 主题系统
- **12 套预设配色**：按色系渐变排列（红→橙→黄→绿→青→蓝→紫→中性灰阶）
- **深浅模式**：跟随系统或手动切换
- **流畅过渡**：主题切换带圆形扩散动画 + 高斯模糊
- 配色方案覆盖 UI 全局（背景、文字、图表、状态栏）
- 状态栏颜色自动适配

### 📋 电源信息
- 厂商、型号、序列号、产地、生产日期
- 固件版本、PMBus 版本
- 额定电压/电流/功率
- 环境/热点最高保护温度
- 状态寄存器实时显示（正常/异常/未知三态）

### 📱 用户体验
- **断联保护**：BLE 断联时全屏高斯模糊遮罩提示
- **自动重连**：断线自动尝试重连
- **低功耗**：图表在页面隐藏时停止更新
- **响应式 UI**：适配不同屏幕尺寸

## 技术架构

### 通信协议
- **BLE 4.0** 连接 ESP32-C3 采集模块
- **GATT 协议** 数据交互
- **JSON 数据包** 传输动态数据与静态信息
- **PMBus** 命令读取电源寄存器

### 数据处理
- **EMA 滤波**（指数移动平均）平滑数据
- **降采样** 保持图表性能
- **线程安全** 的数据采集与 UI 更新
- **帧率自适应** 的 60fps 图表渲染

### 图表绘制
- 自定义 `StreamLineChart` 控件
- 双 Y 轴支持（功率 + 效率）
- 匀速滚动（基于时钟时间，非数据时间戳）
- 曲线渐变淡出效果
- 裁剪区域限制曲线在网格内

### 主题系统
- `ThemeManager` 统一管理配色
- `SharedViewModel` 跨页面共享主题状态
- 动态主题切换（无需重启 Activity）
- `colorOnSurface` / `colorOnSurfaceVariant` 色彩层级

## 系统要求

- Android 8.0 (API 26)+
- Bluetooth 4.0+
- ESP32-C3 采集模块（固件版本 ≥ V1.0）
