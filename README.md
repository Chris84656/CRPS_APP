# CRPS Monitor

基于 Android 平台的 CRPS 服务器电源远程监测与控制应用。通过 BLE 蓝牙连接 ESP32-C3 采集模块，实现电源参数实时采集、可视化展示与远程开关控制。

## 核心功能

### 实时数据监测

应用通过 PMBus 协议采集 CRPS 电源运行参数，经 ESP32-C3 模块蓝牙上报，以 4Hz 频率实时刷新。

**监测参数**

| 参数 | 说明 |
|------|------|
| 输入电压 (VIN) | 电源输入电压 |
| 输入电流 (IIN) | 电源输入电流 |
| 输出电压 (VOUT) | 电源输出电压 |
| 输出电流 (IOUT) | 电源输出电流 |
| 输出功率 (POUT) | 实时输出功率 |
| 转换效率 (Efficiency) | 输出功率与输入功率比值，经 EMA 滤波平滑显示 |
| 风扇转速 | 电源风扇实时转速 |
| 环境温度 | 电源内部环境温度 |
| 热点温度 | 电源内部热点温度 |

**数据曲线**

三组实时滚动图表，支持 60fps 匀速渲染：

1. **电压电流曲线**：输入/输出电压与电流双 Y 轴显示
2. **功率效率曲线**：功率（左轴）+ 效率（右轴，固定 0-100%）
3. **温度曲线**：环境温度与热点温度对比

特性：
- 基于时钟时间的匀速滚动，消除数据时间戳偏差导致的微跳变
- 支持暂停/恢复、拖动查看历史数据
- 页面隐藏时自动停止渲染，节省功耗
- 断联时暂停数据更新，恢复后继续

### 远程电源控制

通过 BLE 远程控制 CRPS 电源开关状态：

- **开机控制**：发送控制指令启动电源
- **关机控制**：发送控制指令关闭电源
- **状态同步**：电源开关状态（开/关）实时同步显示
- **防误操作**：控制操作需二次确认

### 电源信息展示

读取并展示 CRPS 电源的制造商信息与额定参数：

**制造商信息**

- 厂商 ID (MFR_ID)
- 型号 (MFR_Model)
- 版本 (MFR_Revision)
- 序列号 (MFR_Serial)
- 产地 (MFR_Location)
- 生产日期 (MFR_Date)
- PMBus 协议版本

**额定参数**

- 最大输出电流 (MFR_IOUT_MAX)
- 最大输出功率 (MFR_POUT_MAX)
- 环境温度保护阈值 (MFR_MAX_TEMP_1)
- 热点温度保护阈值 (MFR_MAX_TEMP_2)

**状态寄存器**

实时显示以下 PMBus 状态寄存器：

- STATUS_IOUT：输出电流状态
- STATUS_INPUT：输入状态
- STATUS_TEMPERATURE：温度状态
- STATUS_FANS_1_2：风扇状态

每个状态位显示为正常/异常/未知三态。

- **响应式布局**：适配不同屏幕尺寸与方向

## 技术实现

### 通信架构

```
┌─────────────┐    BLE GATT    ┌─────────────┐    PMBus    ┌────────────┐
│  Android    │◄──────────────►│  ESP32-C3   │◄───────────►│  CRPS      │
│  App        │   JSON/Notify  │  采集模块   │   I2C 100kHz│  电源      │
└─────────────┘                └─────────────┘             └────────────┘
```

- **BLE 4.0+ GATT 协议**：建立 Android 与 ESP32-C3 间的数据通道
- **JSON 数据包**：动态数据 250ms 周期上报，静态信息 5s 周期上报（首次连接立即推送）
- **PMBus 协议**：ESP32-C3 通过 I2C 读取电源寄存器（地址 0x58，100kHz）

### 数据处理

- **EMA 滤波**：效率数据采用指数移动平均算法平滑显示
- **LTTB 降采样**：大数据集下采样保持图表渲染性能
- **线程安全**：BLE 回调与 UI 更新通过 ViewModel 解耦
- **帧率自适应**：图表渲染通过 `postInvalidateOnAnimation` 同步显示刷新率

### 图表渲染

自定义 `StreamLineChart` 控件实现：

- 双 Y 轴渲染（功率 + 效率）
- 基于时钟时间的匀速滚动算法
- 曲线渐变淡出效果
- `clipRect` 裁剪限制曲线在网格区域内

### 主题系统

- `ThemeManager`：统一管理 12 套配色方案，支持深浅双模式
- `SharedViewModel`：跨页面共享主题状态，LiveData 驱动 UI 更新
- `ThemeOverlay`：动态切换无需重启 Activity
