# CRPS Monitor

CRPS 服务器电源实时监控 Android 应用，通过 BLE 连接 ESP32-C3 设备，实时监测电源运行参数并远程控制电源开关。

## 功能特性

- **BLE 连接管理**：自动扫描 `CRPS Monitor_` 前缀设备，支持自动重连、MTU 247 协商
- **电源控制**：远程开/关电源，状态实时同步确认，超时自动提示
- **实时数据监测**：输入电压/电流/功率、输出电压/电流/功率、效率、温度、风扇转速
- **数据曲线**：实时滚动曲线图（电压电流、功率效率、温度），支持暂停/拖动查看历史
- **电源信息**：厂商、型号、序列号、产地、生产日期、固件版本、PMBus 版本、额定参数
- **状态寄存器**：STATUS_IOUT / INPUT / TEMPERATURE / FANS 状态显示，点击展开 HEX 值
- **夜间模式**：跟随系统 / 手动切换，圆形扩散动画过渡
- **断联提示**：高斯模糊遮罩（API 31+）/ 半透明降级（API 26+）

## 系统要求

- Android 8.0（API 26）及以上
- 蓝牙 4.0（BLE）支持
- 配合 ESP32-C3 固件使用（BLE 服务 UUID: `0x1815`）

## 使用方法

### 1. 连接设备

1. 确保 ESP32-C3 已上电并处于 BLE 广播状态
2. 打开 APP，进入「电源控制」页
3. 点击扫描按钮（🔄），等待设备列表出现 `CRPS Monitor_XXXX`
4. 选择目标设备，点击「连接」
5. 连接成功后自动订阅数据，状态栏显示「已连接」

> 首次连接成功后，APP 会记住设备地址，下次启动自动重连。

### 2. 电源控制

- 连接成功后，电源开关（MaterialSwitch）可用
- 拨动开关发送开/关机指令，等待 ESP32 回传 `pwr` 字段确认
- 5 秒内未收到确认，提示「操作超时，请重试」，开关自动回弹

### 3. 数据曲线

- 进入「数据曲线」页查看实时滚动曲线
- 曲线以匀速向左滚动，圆点标识最新数据位置
- 点击「暂停刷新」冻结图表，可拖动查看历史数据
- 暂停时点击曲线可查看该时间点的精确数值（气泡提示）
- 点击「实时刷新」恢复滚动

### 4. 电源信息

- 进入「电源信息」页查看静态参数
- 点击状态寄存器行可展开/收起 HEX 原始值（带动画）
- 状态说明：`0x0000` = 正常（绿），`0x0001` = 异常（红），其他 = 未知（黄）

### 5. 夜间模式

- 点击右上角月亮/太阳图标切换
- 三档循环：跟随系统 → 浅色 → 深色
- 切换时有圆形扩散过渡动画

## BLE 通信协议

| 特征值 UUID | 属性 | 用途 | 频率 |
|---|---|---|---|
| `0x2A56` | NOTIFY / READ | 动态数据 JSON | 250ms |
| `0x2A58` | NOTIFY / READ | 静态信息 JSON | 连接后即时 + 5s |
| `0x2A57` | WRITE | 远程控制 | 0x01=开机, 0x00=关机 |

### 动态数据字段

`vin`, `iin`, `vout`, `iout`, `pout`, `eff`, `fan`, `t1`, `t2`, `rt`, `pwr`, `si`, `sn`, `st`, `sf`

### 静态信息字段

`mid`, `mm`, `msn`, `mloc`, `mdate`, `mrev`, `prev`, `rimax`, `rpmax`, `rt1`, `rt2`

## 技术栈

- 语言：Java
- UI：Material 3（DayNight）
- 架构：MVVM + LiveData + 单例 BleManager
- 曲线：MPAndroidChart（匀速滚动 + 动态 Y 轴 + LTTB 降采样）
- JSON：Gson
- 最低版本：API 26（Android 8.0）
